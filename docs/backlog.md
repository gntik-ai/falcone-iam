# Epics and user stories

Generated by `python3 tools/build_docs.py`. S = small, M = medium, L = large; relative complexity, not time promises. No assignees or delivery dates are assumed. P0 = discovery/qualification; P1 = core; P2 = integrations/hardening; P3 = canary/retirement. Phase indicates earliest stage; dependency and release gates still apply.

Each issue uses a stable IAM identifier. Parent links and epic task lists express the hierarchy; no GitHub Project board or native sub-issue relationship is implied.
